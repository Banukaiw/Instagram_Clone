## Features

- User Authentication : Sign In and Sign Up
- Instagram-styled an awesome UI(Home, Notification, Message, Profile, Reels, Search, Post Create)
- Image Uploading for create new Posts/ Delete Posts/ Edit Posts
- Comments to the Posts
- Like/Unlike Posts
- Search Users
- Edit profile details(Image, Full Name, UserName, Password)
- Light and Dark Theme
- Real-time Messaging
- Responsive UI
- Log out feature

## Technologies Used

- React
- JavaScript
- CSS
- Bootstrap Icons
- JSON Server
- WebSocket

## Installation
To install and run this project locally, follow these steps:

1. Clone the repository:
```bash
git clone https://github.com/your-username/Instagram_Clone.git
```

2. Navigate into the cloned directory
```
cd instagram_Clone
```

3. Install the dependencies
```
npm install
```

4. Start the React application(run those command in 3 terminal):
```
npm run dev
```

5. Start JSON Server:
```
npx json-server --watch db/db.json --port 3000
```

6.Start the WebSocket server:
```
node server/websocket-server.js
```
